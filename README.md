# 💼 Job Portal Analytics

Data Analyst Project — Job Portal Analytics Dashboard with data cleaning and visualization.

## 📊 Project Overview

- **Job Market Analysis** — Trends, skills, salaries
- **Data Cleaning Pipeline** — Raw to analysis-ready
- **Interactive Dashboard** — Streamlit-powered
- **Visual Insights** — Plotly charts

## 🛠️ Tech Stack

| Category | Tools |
|----------|-------|
| **Language** | Python 3.13 |
| **Data** | Pandas, NumPy |
| **Visualization** | Plotly |
| **Dashboard** | Streamlit |
| **Data Cleaning** | Custom pipeline |

## 🚀 How to Run

```bash
# 1. Install dependencies
pip install streamlit pandas plotly openpyxl

# 2. Run dashboard
python -m streamlit run dashboard.py

# 3. Or run app
python -m streamlit run app.py
